# Practical Lab Assignment - Control Structures - if/else

1. Converts between Celsius and Fahrenheit temps based on user input.
You can also add Kelvin conversion.
2. Check Whether a Number is Even or Odd.
3. Check Whether a Number is positive or Negative.
4. Check Whether a Character is a Vowel or Consonant.
5. Find the Largest Number Among Three Number.
6. Find if the entered year is a leap year or not.
7. Allows the user to perform basic arithmetic operation on 2 numbers.
You can add error handling for division by zero.
8. BMI Calculator. Use cin, cout. Formula: bmi=weight/height*height).
Provide a classification, underweight, normal, overweight, obese.
9. Nested Condition: Get the age and membership_status as user input. Membership_status can be y or Y. So if the age is bigger or equal to 18, and if the user is a member of our shop, we provide a 10% discount, else we charge fully.
10. Calculate taxes, with the following Conditions:
- If the salary is less than $1500, then there are no taxes.
- If the salary is from 1501 to 3000 $ then the tax should be 10%.
- If the salary is from 3001 to 5000 $ then the tax should be 20%.
- If the salary is above $5000, then the tax should be 30%.
output: Tax percentage. Salary after taxes.
11. Switch
- Use switch statement. Display Monday to Sunday.
- Display arithmetic operator using switch case.
12. Find all roots of a Quadratic equation.
13. Check Whether a Character is an Alphabet or not.
